## 当前设置分组

- 搜索：搜索引擎、搜索行为。
- 外观：背景、动画、主题。
- 导航：快捷入口显示、桌面/手机数量和排序方式。
- 关于：关于本站、当前版本、本机数据和更新日志。

快捷入口从性能概念中独立，但原控件 ID、事件绑定和 localStorage 键全部保留。本机数据入口从原“数据”一级分类迁入“关于本站”，导入、导出和重置能力不变。

一级分类现使用与收藏中心一致的悬浮玻璃工具栏。桌面端内容不再按一级分类隐藏为互斥页面，而是在面板内形成连续滚动内容流；点击分类负责定位对应区域。移动端保留横向滚动分类，并为关闭按钮预留独立空间。

“导航”分组新增收藏中心显示行数选择器，范围为 1 至 6 行，使用 `sksir-bookmark-visible-rows` 保存。值会被限制在合法范围内，损坏或缺失时回退默认布局，不迁移或清空其他快捷入口配置。

## 更新日志

- 用户入口为“设置 → 关于 → 更新日志”。
- `scripts/generate-changelog.js` 读取已提交的 Git 主题和正文。
- 生成器提取具体变化点，并转换为用户可读中文，不展示原始 Commit Message。
- 标签分为“修复”“新增”“改进”“优化”。
- 版本号、文档、测试和低信息提交会被过滤；同一天相同内容会合并。
- 运行时数据写入 `data/changelog.js`，仅在打开分栏时延迟加载。

## 数据兼容

- 搜索引擎继续使用 `se_list`、`se_default` Cookie。
- 壁纸继续使用 `bg_img` Cookie 与 `bg_img_last_src` localStorage。
- 性能继续使用 `sksir-performance-mode`。
- 快捷入口继续使用原 `sksir-quick-launch-*` 键。
- 没有格式迁移，也没有清空旧配置。

导出功能下载包含站点相关 localStorage 和三个配置 Cookie 的 JSON 文件。重置功能有确认步骤，只清理站点命名空间数据和对应 Cookie，然后刷新页面。

## 移动端

- 搜索、外观、导航、关于四个一级分类在窄屏横向排列。
- 二级分栏在窄屏横向滚动。
- 设置内容在单一连续内容区内部滚动，顶部分类工具栏保持可操作。
- 控件继续使用既有安全区和至少 16px 的输入字号规则。
- 更新日志保持单列时间线，标签可换行，不产生页面级横向溢出。
