重新调整收藏中心整体设计方向。

当前问题：
虽然卡片组件已经改为横向布局，但是整体视觉变成传统后台管理页面。

目标：
打造高级、简约、类似 Raycast / Arc 浏览器 / macOS 收藏空间的感觉。

修改：

1. 移除顶部“收藏中心”大标题区域。
   收藏页面不需要重复标题。

2. 一级 Tab 提升视觉等级：
   - 字号明显增大。
   - 增加左右间距。
   - 作为主要导航。

3. 二级分类降低等级：
   - 字号缩小。
   - 作为筛选标签存在。
   - 不要和一级 Tab 平级。

4. 减少页面边框数量：
   - 降低卡片边框亮度。
   - 降低背景透明度。
   - 减少“一个框套一个框”的感觉。

5. 卡片保持当前横向结构：
   图标 + 名称
   描述

   但是：
   - 更轻量。
   - 更像收藏入口，不像管理列表。

6. 整体追求：
   简约、高级、留白、玻璃感。

参考：
Raycast
Arc Browser
macOS Launchpad

不要做成：
后台管理系统
传统网址导航站
