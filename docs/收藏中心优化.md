优化收藏中心顶部工具栏，不修改卡片组件。

目标：
让收藏中心更像 Raycast / Arc / macOS 工具窗口，而不是后台页面。

调整：

1. 移除大搜索框。
   改成右上角搜索图标。

2. 搜索交互：
   默认只显示圆形搜索按钮。
   点击后通过宽度动画展开搜索输入框。
   动画约200-300ms。

3. 设置按钮和关闭按钮缩小。
   与一级分类 Tab 位于同一视觉层级。
   尺寸约32px。

4. 检测状态按钮取消文字。
   改为状态图标。
   点击后显示详细状态。

5. 一级分类 Tab 保留顶部主导航。
   提升字号和视觉权重。
   二级分类作为筛选标签降低权重。

6. 减少顶部区域高度。
   整体感觉：
   悬浮工具栏，而不是后台标题栏。

参考：
Raycast
Arc Browser
macOS 工具栏

保持当前卡片样式不变。
