## 3. 延迟加载边界

- 收藏数据 `data/sites.js` 不在 `index.html` 的首屏脚本链中。
- 用户打开收藏后，`js/main.js` 才依次加载 `data/sites.js` 与 `js/nav-render.js`。
- 收藏状态样式 `css/status-dot.css` 与脚本 `js/status-dot.js` 由独立函数按需加载。
- 因此基线满足：首屏前不请求收藏数据、渲染器或状态检测资源。
- 远程收藏图标由收藏渲染流程处理，不属于首屏批量下载资源。

## 5. 当前关键流程记录

以下为代码路径和页面结构基线：

- 首次打开：早期脚本先设置性能模式、iOS/standalone 高度变量和首屏兜底计时器。
- 搜索框聚焦：沿用现有搜索状态切换；`.all-search` 基础样式包含退出状态所需规则。
- 搜索建议：首页搜索建议由现有 `set.js` 处理。
- 收藏打开：触发收藏数据与渲染器延迟加载，渲染完成后显示收藏内容。
- 分类切换：由收藏渲染后的分类控件处理。
- 设置打开：使用现有独立设置层，内容包含搜索引擎、壁纸、性能与快捷入口。
- 壁纸切换：保存壁纸类型或地址，远程壁纸加载完成后显示，并同步 iOS 同图变量。
