# Phase 1 视觉基础与页面骨架

日期：2026-07-25  
版本：`2026.07.25.1`

## 修改范围

- 在 `:root` 建立文字层级、玻璃表面、边框、阴影、圆角、间距、动画和页面宽度变量。
- 统一首页搜索框、快捷入口、设置按钮以及收藏/设置面板的玻璃视觉语言。
- 调整时间数字、日期和页脚的文字层级。
- 增加键盘焦点可见样式。
- 在 `html.perf-lite` 和 `prefers-reduced-motion` 中覆盖新增的模糊与位移动画。
- 移动端仅调整首页容器内边距，没有修改 iOS 高度、背景、安全区和键盘策略。

## 刻意未做

- 未改变收藏数据或渲染方式。
- 未重组设置内容。
- 未拆分 JavaScript 或移除 jQuery。
- 未改变壁纸 `object-fit`、fixed 定位或 iOS 背景变量。
- 未加入新的 stylesheet 或首屏脚本请求。
- 未修改 `.all-search` 的基础 `translateY(0)` 和搜索态 placeholder 隐藏规则。

## 性能对比

| 项目 | Phase 0 | Phase 1 | 变化 |
|---|---:|---:|---:|
| 主 stylesheet 请求 | 1 | 1 | 0 |
