优化网站图标（favicon）展示样式。

当前问题：

目前网站卡片中的图标已经统一进行了圆形/方形容器包装，比直接显示 favicon 更有设计感。

但是当前效果与 sksir.top 整体玻璃拟态、暗色、高级感风格存在一点割裂：

1. 图标外层容器视觉重量过高。
2. 图标背景、边框、阴影层级太多，像手机桌面 App 图标。
3. 部分黑白 favicon（例如 GitHub、ChatGPT）放入深色容器后辨识度下降。
4. 图标尺寸略大，占据卡片视觉比例较高。

优化目标：

保持当前统一图标容器方案，但降低视觉重量，让图标更融入玻璃风格。

调整方向：

1. 图标容器从“App 图标风格”改为“玻璃悬浮图标”。

当前：

图标
+
明显圆角方框
+
边框
+
阴影

改为：

图标
+
轻微半透明圆形背景
+
弱描边
+
轻微模糊效果


建议：

.site-icon {

    width: 28px;
    height: 28px;

    border-radius: 50%;

    background:
    rgba(255,255,255,0.10);

    border:
    1px solid rgba(255,255,255,0.15);

    backdrop-filter:
    blur(10px);

}


2. 降低图标背景存在感。

减少：

- 边框强度
- 阴影强度
- 背景透明度

不要让图标容器抢过网站名称和卡片内容的视觉。


3. 调整图标大小。

当前图标偏大。

建议：

从约 32px 调整到 26～28px。

保证：

图标清晰

但不要成为卡片主体。


4. 统一所有 favicon 的视觉表现。

不同网站 favicon 本身差异很大：

- 有透明边距
- 有黑白图标
- 有颜色过亮

不要直接改变 favicon。

只通过容器统一：

- 尺寸
- 圆角
- 背景
- 对齐方式


5. 增加 hover 效果。

鼠标经过卡片时：

图标可以轻微增强：

例如：

默认：

opacity:0.95

hover：

brightness(1.1)

不要增加复杂动画。


6. 保持整体设计方向：

skir.top 当前设计方向：

- 暗色背景
- 玻璃拟态
- 半透明面板
- 轻量动画
- 类 macOS / Fluent Design 风格

图标组件需要匹配这个方向。

不要做成：

- 手机桌面图标
- Windows 开始菜单图标
- 过度立体化图标


最终效果目标：

卡片：

网站名称和描述为主体。

图标：

作为视觉辅助。

整体感觉：

“悬浮在玻璃卡片上的小图标”

而不是：

“卡片里面又放了一个小卡片”。


修改前请先在 design-test 页面中测试图标组件，确认风格后再应用到首页、收藏中心、快捷启动等所有地方。
