# Phase 4 收藏中心

日期：2026-07-25  
版本：`2026.07.25.4`

## 完成内容

- 新增收藏中心标题、说明、搜索框和明确关闭按钮。
- 首次打开立即显示面板与加载反馈，数据准备完成后再显示内容。
- 收藏搜索仅在本地执行，不与首页百度联想共用状态。
- 搜索字段包含名称、简介、分类、显式关键字、当前分组和 URL。
- 分组、分类和搜索条件可以组合；清空搜索恢复当前分类结果。
- 没有结果时显示空状态。
- 桌面使用大尺寸居中玻璃面板，内容区内部滚动。
- 手机使用接近全屏的面板，顶部和底部尊重安全区。
- 手机打开收藏中心时隐藏外部设置按钮和访客标记，避免与面板标题栏、搜索和关闭按钮冲突。
- 手机分组和分类均支持横向滚动，输入字号为 16px。
- 手机分组 tab 固定为 40px 高、每项 58px 宽，禁止在全屏 flex 布局中异常拉伸。
- 420px 以下隐藏卡片简介，避免卡片高度失控。
- 补充可见焦点和易触达关闭按钮。

## 加载边界

- `index.html` 仍不直接加载 `data/sites.js`、`js/nav-render.js`、`js/status-dot.js` 或 `css/status-dot.css`。
- 用户打开收藏后才加载收藏数据和渲染器。
- 首个分组先渲染，其余分组继续空闲时延后渲染。
- 图标仍通过 `data-icon-src` 延迟、分批加载；手机每批 4 个。
- 状态检测样式和脚本仍只在打开收藏后按需加载。
- 搜索只操作已经加载的本地 DOM，不发送请求。

## 兼容边界

- `奖励` 分组的锁和隐藏容器保持不变。
- 首页搜索状态、placeholder 和建议逻辑未修改。
- 没有修改 iOS 键盘、整页位移、壁纸缩放或背景高度变量。
- 页面继续使用一个主 stylesheet。
