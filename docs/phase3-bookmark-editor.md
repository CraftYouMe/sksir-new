# Phase 3 本地收藏管理器

日期：2026-07-25  
版本：`2026.07.25.3`

## 使用方式

```powershell
node scripts\manage-sites.js
```

默认地址为 `http://127.0.0.1:4173`。端口冲突时可使用：

```powershell
node scripts\manage-sites.js --port=4174
```

服务仅监听本机，只提供编辑器三个固定静态文件及 `/api/sites`、`/api/validate`、`/api/save` 三个固定数据路由。

## 已实现功能

- 展示全部分组与网站；
- 按名称、URL、简介或分类搜索；
- 分组筛选；
- 新增和编辑网站；
- 删除二次确认；
- 选择分组和已有分类，或直接输入新分类；
- 上下调整条目顺序；
- 自动建议唯一稳定 ID；
- 自动或自定义图标；
- 快捷入口候选、状态检测和隐藏状态高级选项；
- 同组重复 URL、重复 ID、非法协议和空字段检查；
- 保存前显示新增、修改和删除数量；
- 未保存修改离开提醒；
- UTF-8 临时文件写入、双文件替换、失败回滚和写后读取检查。

## 安全边界

- 不接受文件路径参数；
- 不提供任意静态目录或通用文件接口；
- 不执行用户输入的命令；
- 请求体限制为 2 MiB；
- 不监听 `0.0.0.0`；
- 线上页面没有新增写入 API；
- 隐藏分组保存时必须保留锁配置，隐藏分组内站点必须保持 `hidden: true`。

- `GET /api/sites`：200，6 个分组、86 个站点；
- `GET /`：200，编辑器 HTML 正常返回；
- 空分组和空站点提交：400，原文件不变；
- 使用当前完整数据调用 `/api/save`：成功，写后仍为 6 个分组、86 个站点；
- `node scripts/validate-sites.js --strict`：0 错误、0 警告；
- 语法检查覆盖服务端和编辑器脚本。

当前自动测试覆盖数据读取、拒绝非法数据和安全写回。删除确认、未保存离开提醒及键盘表单操作需要在可交互浏览器中继续人工回归。
