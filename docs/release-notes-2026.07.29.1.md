# Sksir New `2026.07.29.1` 发布说明

发布日期：2026-07-29

## 主要变化

- 设置中心左侧“数据”分类调整为“关于”，并更换为信息图标。
- “关于”分类包含“关于本站”和“更新日志”两个二级分栏。
- 原本机数据导入、导出和重置能力保留在“关于本站”。
- 新增玻璃拟态时间线更新日志，桌面端和移动端沿用现有设置中心布局。
- 更新日志提供“修复”“新增”“改进”“优化”四类标签。

## 日志内容生成

- `scripts/generate-changelog.js` 从已提交的 Git 主题和正文提取更新事实。
- 生成内容会移除版本号、文档、测试、文件名等内部噪声。
- 英文和技术性描述会转换为用户可读中文，页面不直接展示 Commit Message。
- 生成器针对快捷入口、搜索、壁纸、缓存、iOS、设置中心等内容提取具体变化。
- 无法得出有效信息的提交不会展示；同一天完全相同的记录会合并。
- 当前生成结果包含 211 条有效记录和 203 个不同摘要。

## 性能与兼容

- `data/changelog.js` 仅在用户打开更新日志时加载，不阻塞首屏。
- 提交内容使用文本节点渲染，不作为 HTML 注入页面。
- 桌面端使用纵向时间线卡片；移动端收窄为单列，并保持标签换行。
- 页面版本已同步为 `2026.07.29.1`。

## 验证

- `node scripts/check.js`：29 项通过。

- 桌面端“关于”和“更新日志”局部视觉检查通过。


```powershell
git diff --check
```
