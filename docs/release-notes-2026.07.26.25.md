# Sksir New `2026.07.26.25` 发布说明

发布日期：待定  
发布状态：候选版本，等待跨设备验收

## 主要变化

- 完成极简玻璃视觉基础、首页层级、收藏中心和设置中心重构。
- 收藏数据改为规范化模型，并提供本地可视化收藏编辑器。
- 首页快捷入口支持自定义、收藏添加、数量设置、点击排序和拖动排序。
- 收藏中心支持分组、分类、搜索、按需渲染和延迟图标加载。
- 搜索建议支持本地收藏与必应联想合并，并具备离线、超时和竞态保护。
- 搜索引擎支持候选面板、Alt + 1～4、默认切换及本地新增、编辑和删除。
- 设置中心重新分组，支持数据导出、重置、壁纸和性能模式。
- JavaScript 按职责拆分为存储、收藏、设置、壁纸、快捷入口、搜索和启动模块。

## 性能与稳定性

- 收藏数据、收藏渲染和状态检测继续保持按需加载。
- 状态检测资源只在需要时加载，不阻塞首屏。
- 首屏壁纸、时间、搜索框和基础布局继续优先。
- `bootstrap.js` 统一负责首屏揭示及首屏后的非关键任务调度。
- 本地 MiSans UI 子集继续使用，未恢复完整远程字体。
- `perf-lite` 与减少动态效果模式继续保留。

## 容错与安全

- 搜索建议失败不会清空本地收藏结果。
- 离线时不会请求远程联想。
- 损坏的搜索引擎 Cookie 会回退到内置列表。
- 快捷入口会清理非法协议、重复 URL、异常点击计数和无效排序。
- `/api/check` 继续限制为收藏域名，并拦截本地、内网、link-local 和 metadata 地址。
- Service Worker 只负责清理旧缓存并注销，不提供离线缓存或安装能力。

## 兼容性说明

- jQuery 仍有 159 处生产调用，当前版本继续保留 `jquery-3.6.0.min.js`。
- 搜索引擎 Cookie 格式和快捷入口 localStorage 键保持兼容。
- iOS 高度变量、壁纸同图兜底、安全区和早期启动逻辑未重写。
- 搜索引擎面板继续从搜索框下方展开。
- `奖励` 分组继续保持前端隐藏，没有移入公开分组。
